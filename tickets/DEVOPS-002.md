# DEVOPS-002 — Safe Collaboration for Five Developers

Five developers will work on NovaCart at the same time, and the team needs a way to collaborate without letting unfinished changes slip into production-ready code.

Design and implement a Git/GitHub workflow that supports independent work, review, automation, and urgent fixes.

**Requirements:** reviewed changes, protected production code, automated checks before merge, and an emergency-fix path.

Assume you have the necessary GitHub repository permissions to configure appropriate repository-level protections and merge controls.

**Deliverable:** implemented repository configuration plus `docs/git-strategy.md`.

This is not a documentation-only task. Implement the workflow in the repository you created for yourself to track your cohort work, and document any GitHub branch protection or merge settings that must be configured at the repository level.

Keep the workflow simple and practical. Choose an approach that five developers can follow consistently, justify why it fits this project, and avoid unnecessary complexity.

Document:

* the workflow you chose
* how developers contribute changes
* how production-ready code is protected
* how emergency fixes are handled
* the trade-offs of your approach

Do not assume or use a specific branching model unless you can justify why it fits the project.
